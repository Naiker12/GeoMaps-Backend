FUNCION: USUARIOS

Archivos principales:
- app/api/v1/users.py
- app/db/models/user.py
- app/schemas/user.py
- app/infrastructure/repositories/user_repository.py

Endpoints principales:
- POST /api/v1/users/
- GET /api/v1/users/
- GET /api/v1/users/me
- PATCH /api/v1/users/me
- PATCH /api/v1/users/{user_id}
- DELETE /api/v1/users/{user_id}

Flujo:
1. Se crean, consultan, actualizan o eliminan usuarios.
2. Las rutas de usuario actual dependen del token autenticado.
3. Las rutas administrativas deben validar permisos antes de modificar otros usuarios.

Relaciones:
- Auth crea o resuelve usuarios.
- API keys, proyectos, capas y soporte dependen de user_id.
