FUNCION: PROYECTOS

Archivos principales:
- app/api/routes/project_routes.py
- app/services/project_service.py
- app/services/project_asset_service.py
- app/repositories/project_repository.py
- app/repositories/project_asset_repository.py
- app/schemas/project.py
- app/schemas/project_asset.py

Endpoints principales:
- POST /api/v1/projects/
- GET /api/v1/projects/
- GET /api/v1/projects/public
- GET /api/v1/projects/{id}
- PUT /api/v1/projects/{id}
- DELETE /api/v1/projects/{id}
- GET /api/v1/projects/{id}/assets
- POST /api/v1/projects/{id}/assets
- PATCH /api/v1/projects/{id}/assets/{asset_id}
- DELETE /api/v1/projects/{id}/assets/{asset_id}
- GET /api/v1/projects/{id}/models/renderable
- PATCH /api/v1/projects/{id}/models/{asset_id}/transform
- POST /api/v1/projects/{id}/images
- POST /api/v1/projects/{id}/models
- POST /api/v1/projects/{id}/shapefile
- GET /api/v1/projects/{id}/lots/geojson
- PUT /api/v1/projects/{id}/lots/{lot_id}

Flujo:
1. Usuario autenticado crea o administra proyectos.
2. Los proyectos pueden tener assets, imagenes, modelos 3D, shapefiles y lotes.
3. El servicio coordina base de datos, storage y transformaciones.
