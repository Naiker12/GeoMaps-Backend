DOCUMENTACION BACKEND POR FUNCION
Fecha: 2026-06-02

Objetivo:
Organizar la documentacion tecnica del backend por funcion/modulo, sin tocar la logica del sistema.

Estructura:
Cada subcarpeta representa una funcion principal del backend. Dentro hay tres archivos:

1. 01_flujo_tecnico.txt
   Describe endpoints, archivos principales, servicios y flujo general.

2. 02_seguridad.txt
   Revisa autenticacion, autorizacion, entradas peligrosas, archivos, permisos y riesgos.

3. 03_buenas_practicas.txt
   Lista recomendaciones de mantenimiento, pruebas, performance y mejoras futuras.

Funciones incluidas:
- admin
- api_keys
- auth
- busqueda
- capas
- cartografia
- descargas
- health
- ia
- ogc
- proyectos
- reportes
- soporte
- usuarios

Nota:
Esta carpeta es documentacion operativa. No debe importarse desde el codigo ni afectar ejecucion.
